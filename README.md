# 🚌 БУДОВА RUSH

Оригінальна браузерна аркада українською про гонку на будову. Жодних зовнішніх бібліотек, платних шрифтів чи сторонніх графічних ресурсів: персонажі, бус та всі перешкоди намальовані через Canvas 2D і CSS.

## Запуск

Відкрийте `index.html` у браузері або розмістіть репозиторій через **GitHub Pages**: `Settings → Pages → Deploy from a branch → main / (root) → Save`. Гра працює без сервера і без інтернету після завантаження файлів.

## Правила

| Перешкода | У бусі | Пішки |
| --- | --- | --- |
| Алкотрубка | Миттєвий кінець гри | −60 очок і −60 прогресу повернення |
| Стаканчик | На 6 секунд різкіше керування | На 6 секунд швидший біг і різкіше керування |
| Начальство | Забирає бус, гра переходить у режим бігу | Обнуляє очки та прогрес повернення |

- **У бусі:** `+25 очок/сек`.
- **Пішки:** `+20 очок/сек`. Отже бус приносить **на 25% більше**, ніж біг.
- **Повернення буса:** здобути **160 очок прогресу** під час бігу; штрафи можуть зменшувати цей прогрес.
- Ухиляйтеся від перешкод та встановлюйте локальний рекорд (зберігається у `localStorage`).

## Керування

- `←` / `→` або `A` / `D` — вліво та вправо.
- `P` або `Escape` — пауза / продовження.
- `Enter` — старт / рестарт.
- На смартфоні — дві великі екранні кнопки, які можна утримувати.

## Технології

HTML5, CSS3, JavaScript (Canvas 2D, `requestAnimationFrame`, `localStorage`). Всі зображення є власною програмною графікою, сторонні ассети не використовуються.
